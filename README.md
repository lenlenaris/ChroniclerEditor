# Chronicler Editor

A web-based character editor designed for SillyTavern. Runs entirely in your browser with no server required.

## Features

- **Character Cards** - Create and edit character cards with multi-version support. Export as JSON or PNG.
- **World Books** - Manage lorebook entries in SillyTavern-compatible format.
- **User Personas** - Create player character profiles. Export as TXT or Markdown.
- **Presets** - Manage prompt presets in SillyTavern format.
- **Notes** - Organize custom notes with user-defined fields.
- **Version Control** - All content types support multiple versions with side-by-side comparison.
- **Global Search** - Search and replace across all content with a single operation.
- **Token Counter** - Real-time token calculation powered by tiktoken.

## Technical Details

- Pure HTML, CSS, and JavaScript. No frameworks or build tools required.
- Data stored locally in IndexedDB. Your data never leaves your browser.
- Bilingual interface: English and Traditional Chinese.
- PWA-ready for offline use.

## Data Safety

All data is stored in your browser's local storage. Export your data regularly to prevent loss from browser data clearing.

# Chronicler Editor

專為 SillyTavern 設計的網頁版角色編輯器。完全在瀏覽器中運行，無需伺服器。

## 功能

- **角色卡** - 創建和編輯角色卡，支援多版本管理。可匯出為 JSON 或 PNG。
- **世界書** - 管理世界書條目，相容 SillyTavern 格式。
- **玩家角色** - 創建玩家角色檔案。可匯出為 TXT 或 Markdown。
- **預設提示詞** - 管理 SillyTavern 格式的提示詞預設。
- **筆記本** - 使用自定義欄位整理筆記。
- **版本控制** - 所有內容類型皆支援多版本管理與並排對比。
- **全域搜尋** - 一次操作即可搜尋並取代所有內容。
- **Token 計算** - 使用 tiktoken 即時計算 token 數量。

## 技術細節

- 純 HTML、CSS、JavaScript，無需框架或建構工具。
- 資料儲存於瀏覽器的 IndexedDB，資料不會離開你的裝置。
- 雙語介面：英文與繁體中文。
- 支援 PWA 離線使用。

## 資料安全

所有資料皆儲存於瀏覽器本機。請定期匯出備份，以防瀏覽器清除資料導致遺失。
